## Project continuity

If the current repository contains `.project-continuity/state.md`, use the
`project-continuity` skill before substantive project work. If the current client cannot
resolve the skill by name (for example, skill discovery fails or the skill does not appear
available), read and follow `~/.agents/skills/project-continuity/SKILL.md` directly instead.

If no continuity file exists but the work is clearly likely to span multiple sessions and
would materially benefit from cross-session handoff, ask once whether the user wants project
continuity enabled. Do not initialize it without user consent.
